## Overview

**SD Furniture** is a multi-view single-page web experience built to demonstrate how contemporary furniture and interior studios can present bespoke collections online—without heavy e-commerce clutter or third-party frameworks.

Engineered purely with semantic HTML, modular CSS, and native browser JavaScript, every transition, scroll reveal, and interactive blueprint runs smoothly with zero build steps.
